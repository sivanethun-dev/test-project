# 投資リテラシー基礎メモ（初心者〜再入門）

**作成日:** 2026-08-12  
**目的:** SNSの「買い推奨」に流されず、自分の判断軸を持つための最低限の地図  
**前提:** 売買推奨ではない。これまでの評価レポート（第1〜4弾）とセットで使う。

---

## 1. まず覚える3つの区別

| 言葉 | 意味 | 例 |
|------|------|----|
| **投資** | 事業や資産の価値増加・配当などを見込んで、時間を味方につける | 長期で指数や優良株を持つ |
| **投機** | 短期間の値動きで売買益を狙う | 「今日上がる5銘柄」 |
| **勧誘／煽り** | 相手の行動を起こさせるための演出 | LINEキーワード、Ferrari写真、300倍予言 |

SNSで困ったら、まず「これは投資？投機？勧誘？」と分類する。  
これまでのレポートで「破棄」としたものは、ほぼ投機＋勧誘です。

---

## 2. 株でお金が増える／減る仕組み（超基本）

株を持つと、だいたい次の2つで損益が決まります。

1. **値上がり益（キャピタルゲイン）** … 買った価格より高く売れた差分  
2. **配当（インカムゲイン）** … 会社が利益の一部を株主に分配  

さらに日本では、

- **株主優待**（商品・サービス）がある会社もある  
- 売却益・配当には通常 **約20.315%の税金**（NISA口座なら非課税枠あり）

「利回り4%」は、だいたい  
**年間配当 ÷ 株価** です。  
（例: 株価1,000円・年間配当40円 → 4%）

**取得利回り（Yield on Cost）** は  
**今の年間配当 ÷ 自分が買ったときの価格**。  
増配が続くと上がって見えますが、今の時価に対する利回りとは別物です（第4弾で検証済み）。

## 3. リスクの正体（怖がるポイントを具体化）

| リスク | 中身 |
|--------|------|
| 価格変動 | 上下する。短期ほどノイズが大きい |
| 企業リスク | 業績悪化・減配・倒産・増資（持ち分が薄まる） |
| テーマリスク | 「AI」「レアアース」など流行テーマは期待が先行しやすい |
| 流動性 | 売買量が少ないと、売りたいときに不利な値段になりやすい |
| 自分リスク | 焦って高値追い、損を取り返そうとして深追い（最も多い） |

**分散**とは、「1社・1テーマに人生を賭けない」こと。  
全部を理解してから買う必要はないが、**分からないものに大きく張らない**のがリテラシーの中核です。

---

## 4. 口座の最低知識（日本）

- **特定口座（源泉徴収あり）** … 税金計算を証券会社がほぼ代行。最初はこれで十分な人が多い  
- **NISA（成長投資枠・つみたて投資枠）** … 非課税で運用できる枠。長期・分散向き  
- **単元** … 日本株は通常100株単位。証券会社の「1株から」サービスなら少額で練習できる  

最初のゴールは「大勝ち」ではなく、

1. 口座を開いて  
2. 少額で売買・配当の体験をし  
3. 自分の感情（焦り・恐怖）を観察する  

ことです。

## 5. SNS情報のリテラシー（このシリーズの核心）

### すぐ切るサイン（これまでに何度も出た）

- 「今すぐ」「一度しか言わん」「必ず」「底だ」  
- LINE／DM＋キーワード（323、55、9…）  
- Ferrari・億り人写真・あり得ない配当明細  
- 現値数十円→予測数千〜数万倍  
- テーマだけ本物で、銘柄は隠す／無関係銘柄を並べる  

### 残してよいサイン

- 公式IR・適時開示・会社FAQと数字が一致する  
- 事業の仕組みが説明できる（何を売って、誰が買うか）  
- 「調べる入口」になっていて、「買え」で終わらない  

### 実務ルール（おすすめ）

```text
SNSで気になる
  → テーマだけメモ（冷却、光電融合、年4回配当 など）
  → 銘柄名は一次情報で自分確認
  → 「買え／今すぐ／DM」が付いていたらその投稿は破棄
  → 自宅リストと突合してから、少額かどうかを決める
```

## 6. これまでのレポートをどう使うか

| レポート | リテラシー上の学び |
|----------|-------------------|
| 第1弾 | 詐欺・LINE誘導の典型。QPSは「調査候補」止まり |
| 第2弾 | 北洋銀行の年4回配当＝一次情報で確認できる例 |
| 第3弾 | 過去のすごい倍率 ≠ 未来の約束。シミュレーションに注意 |
| 第4弾 | テーマ（冷却・光）は有用、導線は破棄。切り口思考 |

**上達の定義:** 銘柄を当てることではなく、  
**「これは使える情報か／演出か」を30秒で仕分けられること。**

## 7. 最初の90日学習プラン（負担が少ない版）

### 週1回だけやること（30〜60分）

1. 気になった投稿を1つだけ選ぶ  
2. 本メモの「切るサイン」で仕分け  
3. 残すなら、公式サイトか決算短信を1ページだけ見る  
4. GitHubのレポートに「なぜ残した／捨てた」を一言追記する感覚でメモ  

### まだやらなくていいこと

- 信用取引・レバレッジETFの長期放置  
- SNSの「毎日上がる5銘柄」フォロー運用  
- 全財産を個別株へ集中  

### やると効く Habit

- **金額ルール:** 1銘柄に入れても困らない金額だけ  
- **冷却期間:** 欲しくなったら24時間置いてから判断  
- **一次情報優先:** 株探・会社IR・取引所開示 ＞ SNS
